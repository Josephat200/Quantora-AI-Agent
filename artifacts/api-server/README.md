# Quantora AI API Server

This is the TypeScript/Express backend for Quantora AI. It follows the imported
workspace's existing Node stack and does not connect to the database package.

## Architecture

- `src/routes/` contains thin HTTP routes under `/api/v1`.
- `src/services/` contains AI and tool business logic.
- `src/middleware/` contains bearer-token authentication.
- `src/lib/` contains settings, security helpers, logging, and temporary stores.
- `uploads/` contains temporary uploaded bytes and is not persistent storage.

`users`, `conversations`, and `files` are intentionally in-memory. They are isolated
behind the route/service boundary so a future repository implementation can replace
them without changing the API contract. Do not treat this mode as production
persistence.

## Run

```bash
pnpm install
PORT=5000 pnpm --filter @workspace/api-server run dev
```

The service starts without a database or AI key. Visit `/api/v1/health`, `/docs` is
not generated by this Express import, and the frontend uses the documented `/api/v1`
routes directly. Configure an OpenAI-compatible provider before using chat or agents.
